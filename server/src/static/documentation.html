API Overview

The Research Project Management API provides a comprehensive set of endpoints to manage academic research projects, teams, and users in an educational institution.

This API is designed for educational institutions to streamline the research project management process, facilitate collaboration between students and supervisors, and provide administrative oversight.

Authentication

Secure JWT-based authentication with role-based access control for students, supervisors, and administrators.

Team Management

Create and manage teams, assign supervisors, and facilitate collaboration between team members.

Project Management

Create, track, and evaluate research projects throughout their lifecycle, from proposal to completion.

API Endpoints

Authentication
  • POST /auth/register - Register a new user
  • POST /auth/login - Log in an existing user
  • GET /auth/profile - Get the current user's profile
  • PUT /auth/profile - Update the current user's profile
Team Management
  • GET /teams - Get all teams
  • POST /teams - Create a new team
  • GET /teams/:id - Get team by ID
  • POST /teams/:teamId/assign-supervisor - Assign supervisor to team
Students
  • GET /students/profile - Get student profile
  • GET /students/deadlines - Get deadlines for student
  • POST /students/submit-report - Submit a report
  • GET /students/results - Get all student results
Supervisors
  • GET /supervisor/profile - Get supervisor profile
  • GET /supervisor/projects - Get supervised projects
  • POST /supervisor/projects/:projectId/evaluate - Evaluate project
  • GET /supervisor/teams - Get supervised teams
Sessions
  • GET /sessions - Get all sessions
  • GET /sessions/current - Get current active session
  • POST /sessions - Create a new session
  • PATCH /sessions/:id - Update a session
Dashboard & Analytics
  • GET /dashboard/student - Get student dashboard data
  • GET /dashboard/supervisor - Get supervisor dashboard data
  • GET /dashboard/admin - Get admin dashboard data
  • GET /admin/analytics - Get system analytics

Authentication

JWT Authentication

The API uses JWT (JSON Web Token) for authentication. To access protected endpoints, you must include a valid JWT token in the Authorization header of your requests.

How to authenticate:

  1. Login with your credentials to obtain a JWT token
  2. Include the token in the Authorization header of your requests:
// Login to obtain token
POST /auth/login
// Request body
{
  "email": "user@example.com",
  "password": "yourpassword"
}

// Response with token
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": { ... }
}

Using the token:

// Include token in Authorization header
GET /auth/profile
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
